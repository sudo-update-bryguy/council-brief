About council-brief

Blue Ridge and Fannin County record their public meetings, but they run close to an hour and few people can watch them. Paid services sell AI summaries of these same meetings. This site does it for free, and the code is public so anyone can check how it works.

How a summary is made

  1. The city's Agenda Center and the boards' YouTube channels are checked for new meetings.
  2. The recording is transcribed on a computer with Whisper, an open speech-recognition model.
  3. Voices are separated and named only when the recording gives evidence, like someone being called on by name.
  4. A small AI model that runs on that same computer writes the summary. Code finds the votes, checks every quote against the transcript, and marks anything it can't confirm.

How accurate it is

Each version of the summarizer is scored against answer keys built from the official minutes. The current version found 5 of 6 votes in the test meeting and never stated a wrong result as fact; when it can't tell how a vote went, it says the result is unclear. Vote counts are reported as heard on the recording, which doesn't always match the minutes. Full results.

The official minutes are the record. Use this site to find what happened and jump to it, then check the minutes for anything that matters to you.

Keeping it running

The site costs nothing to run today. The Support page lists two upgrades that donations would pay for, better summaries and email alerts by topic, and exactly what each would cost.
